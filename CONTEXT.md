# Virtual Assistant Portfolio — Project Context

## 1. Project Overview

This project is a professional portfolio website for **Iverene Causapin**, positioned as an **Administrative Virtual Assistant** specializing in organized records, data management, inbox and calendar coordination, business communication, and administrative support.

The portfolio should communicate one central idea:

> **Reliable administrative support that keeps information, communication, and daily operations organized.**

The website is not intended to present the user primarily as a graphic designer or developer. Canva and digital tools are supporting capabilities that strengthen the user's administrative service offering.

The portfolio should demonstrate not only what the user can do, but also how the user approaches administrative work:

* Organized
* Detail-oriented
* Clear
* Reliable
* Systematic
* Professional
* Proactive
* Confidential
* Process-focused

The portfolio should use realistic practice projects and documentation rather than implying employment or client experience that has not occurred.

---

# 2. Target Audience

The primary audience consists of:

# 14. Content Principles

All website content should follow these principles:

### Clear

Avoid unnecessarily complex language.

### Professional

Use business-appropriate wording without sounding overly corporate.

### Specific

Describe actual tasks and deliverables rather than vague claims.

### Honest

Clearly distinguish between:

* Actual experience
* Academic experience
* Practice projects
* Simulated business scenarios

### Client-Focused

Explain how the user's work helps a business.

Instead of:

> "I know Google Sheets."

Use:

> "I organize and maintain spreadsheets so business data is easier to track, review, and update."

Instead of:

> "I can use Canva."

Use:

> "I create professional business documents, presentations, announcements, reports, and social media materials using Canva."

---

# 15. Overall Portfolio Goal

The finished portfolio should communicate:

> **I can take scattered information, organize it into a clear system, and help keep day-to-day business operations running smoothly.**

The portfolio should demonstrate this through actual examples rather than relying solely on claims.

The strongest evidence should come from the Portfolio section, where visitors can inspect the user's actual work across records, spreadsheets, email, calendars, and business communications.
